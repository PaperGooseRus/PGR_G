# Механики и инварианты (v3)

## Уровни

У каждого игрока и NPC может быть навык по любой профессии. Стартовые NPC специализируются на разных ремёслах. Профессиональный XP увеличивается за обоснованные попытки, в том числе с браком. Отсутствующий входной материал не даёт XP.

Неудача может уничтожить расходуемые материалы, но не позволяет получить новый предмет. Повторная попытка требует новый реальный материал. Опытный мастер повышает вероятность выполнения обычной операции, но не получает право создавать из пустоты.

## Цепочка меча

`рудное месторождение → руда → алхимик → металл → кузнец → клинок`.

`лес → древесина → плотник → рукоять`.

`клинок + рукоять → операция сборки → меч`.

`месторождение камней → камень + реальный меч → ювелир → тот же меч с инкрустацией`.

Это **модель зависимостей**, а не фиксированный рецепт «3 железа + 2 дерева». Два клинка одинакового типа могут иметь разные качество и исходный элемент. В будущем будут добавлены допуски формы и сборочные интерфейсы.

## Алхимические цепочки

`первичный источник №6 → primal-ore №1 → extract → элемент №1`.

Два отдельных лота элемента №1 гарантированно дают элемент №2 при `mix`. Чтобы получить №3, требуется физически произвести элемент №2 и дополнительно взять №1. Чем больше целевой индекс, тем выше риск потери обоих реагентов.

Обычная руда с узла №1 нужна для выплавки металла; она **не является способом бесплатно получить элемент с высоким номером**. Таким образом, сложная алхимическая прогрессия не обходится добычей лучшей руды.

## Правила владения и заказов

Для передачи ресурс должен находиться у передающего персонажа. Заказ может принять только другой NPC. При создании заказа фактически перемещаются необходимые лоты или предметы; если материальный лот содержит несколько единиц, создаётся дочерний лот с собственным ID.

Заказ резервирует именно эти экземпляры. Их нельзя использовать вне заказа, пока он открыт. При отмене они возвращаются заказчику. При исполнении результат передаётся заказчику. При неудаче неизрасходованные детали также возвращаются. У каждого заказа только один финальный статус.

## Промежуточные аномалии

Система генерирует для мира скрытую комбинацию направления взгляда, количества прыжков и количества последовательных дней молитвы. Условие не является готовым рецептом. Даже его выполнение открывает эффект только при крайне редком броске.

- `structural-memory` — промежуточный эффект металлической детали.
- `harmonic-wood` — промежуточный эффект древесной детали.

При сборке детали передают аномальный признак и резонанс итоговому предмету. Игрок может исследовать аномальный предмет, получить знание и передать его NPC, после чего воспроизведение немного легче. Само условие при этом не снимается.

**Примечание:** пока возможных состояний всего два; дальнейшая версия сможет процедурно сочетать элементарные изменения физических свойств вместо фиксированного названия эффекта. Реалистичная причинность для прыжков и молитв не предполагается: это намеренно игровые, необъяснимые закономерности.

## Почему отсутствует бесконечная добыча

Каждый начальный ресурсный узел имеет конечное `remaining`. В v3 нет автоматического возобновления запасов. Позднее появятся регенерация биологических ресурсов, перемещение караванов и ресурсные рынки; но любые источники будут явно описаны правилами мира.
