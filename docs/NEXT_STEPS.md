# План после v0.2 — до 5 тестируемых этапов

1. **API-адаптер старого RPG Core v3.** Связать реальные материалы и профессии с `LedgerStore`, не переписывая формулы. Проверка: добытая в 3D руда становится входом существующего алгоритма алхимии.
2. **Производственные заказы и долговременные задачи NPC.** Единый планировщик событий для всех NPC вместо отдельного потока на каждого. Проверка: кузнец делает клинок в фоне активной игры, заказ переживает перезапуск.
3. **Универсальные детали и анимация.** Создавать из физических материалов предмет из нескольких кубических частей; движения рук/ног задавать математически. Проверка: клинок и рукоять видны как один новый экземпляр.
4. **Отделение потока симуляции.** Командная очередь/снимки, один владелец SQLite, UI в графическом потоке. Проверка: гонки, двойная добыча и конфликт за один предмет не воспроизводятся.
5. **Сетевой сервер без blockchain.** Авторизация, приватность, request-id, публичные подписанные контрольные хеши. Проверка: два реальных сетевых клиента не могут дублировать ресурсы, вмешиваться в чужие инвентари или повторно завершать одну сделку.

Выполнять следующий этап только после измерения текущей версии на Windows/MSYS2 UCRT64.
